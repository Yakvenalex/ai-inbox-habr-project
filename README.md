# ai-inbox-habr-project

**AI Inbox** — учебный мультимодальный ассистент для почты и задач на Python.
Проект создаётся для технической статьи на Хабре в сотрудничестве с
[AnyModel](https://anymodel.org/).

Ассистент поможет разобрать входящие письма, подготовить черновики ответов,
создать задачи из текста, голосовых команд и изображений, а также сформировать
и озвучить ежедневный дайджест.

## Статус

Подготовительный этап. Предварительно проверены выбранные модели, чтение почты
через IMAP и доставка тестового письма через SMTP. Реализация приложения ещё
не начата; команды установки и запуска появятся вместе с рабочим кодом.

## Планируемые возможности

- Просмотр непрочитанных писем и краткие сводки.
- Подготовка и редактирование локальных черновиков ответов.
- Задачи с дедлайнами из текста, писем и изображений.
- Голосовой ввод с просмотром расшифровки перед выполнением команды.
- Ежедневный дайджест в 09:00 по Москве и озвучка ответов.
- Веб-интерфейс и REST API со Swagger UI.

В первой версии агент готовит черновики; самостоятельная отправка писем в
пользовательские сценарии не входит.

## Технологии

- **Backend:** Python, FastAPI, Pydantic, OpenAI Agents SDK.
- **Хранение данных:** SQLite, SQLAlchemy, Alembic.
- **Расписание:** APScheduler.
- **Интерфейс:** Jinja2, Tailwind CSS и daisyUI через CDN, без Node.js-сборки.
- **Почта:** IMAP; SMTP уже проверен для дальнейшего расширения.
- **AI:** единый API AnyModel для LLM с распознаванием изображений, ASR и TTS.

Код будет разделён по правилам чистой архитектуры: доменная модель, прикладные
сценарии, инфраструктурные адаптеры и слой представления. API, веб-интерфейс и
инструменты агента будут использовать общие прикладные сценарии.

## Выбранные модели

- **LLM и OCR:** `ag/gemini-3.8-flash-low`.
- **Распознавание речи:** `dg/nova-3`.
- **Озвучка:** `anyvoice/builtin-7` — «Спокойный женский».

Идентификаторы задаются через окружение. Доступность маршрутов и результаты
работы зависят от провайдера; предварительные проверки не являются гарантией
стабильности сервиса.

## Локальная конфигурация

Шаблон настроек находится в [.env.example](.env.example). Для будущего запуска
нужны ключ AnyModel, почтовый ящик с паролем приложения, а также отдельные
логин, пароль и JWT-секрет для входа в AI Inbox.

Приложение планируется запускать локально по адресу `http://127.0.0.1:18763`.
Доступ к моделям, почте и CDN требует интернета. Для автоматического дайджеста
компьютер и приложение должны быть запущены.

Локальный `.env`, почтовые данные, SQLite, аудио и другие runtime-файлы исключены
из Git. В репозитории публикуются только безопасные примеры конфигурации.
