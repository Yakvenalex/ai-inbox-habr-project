# Контекст для новой сессии: статья

Проект для Хабра в сотрудничестве с AnyModel. Автор — Алексей Яковенко,
канал «Легкий путь в Python». Статья пока не написана. Перед её началом учесть
результаты ручной приёмки владельца по final-checklist.md.

Начать с README.md, decisions.md, verification.md и article-outline.md.
README описывает актуальные возможности, verification — реальные результаты и
непроверенные ограничения. Локальная SPEC.md намеренно не публикуется; .env и data/
содержат приватные данные. Не переносить их содержимое в статью или репозиторий.

Опорный пример: учебный счёт ЖЮ-3082 на 89 406,75 руб., срок 19 ноября 2026 года
09:20 Europe/Moscow. Изображение — tests/fixtures/invoice.png. Демостенд с 25
письмами и fake-провайдерами — tests/e2e/demo_server.py, порт 18764.
Медленный потоковый ответ включается фразой со словом «стриминг». Fake TTS — тихий
тон; качество настоящего голоса этим стендом не демонстрируется.

Нити объяснения кода: чистые сценарии и общие tools; подтверждённые результаты
вместо обещаний модели; vision/ASR с подтверждением; MD и очистка HTML; SSE и повтор
request_id без повторного внешнего действия; SMTP snapshot + отдельное согласие;
IMAP readonly/прочитанность/UID MOVE; UID-пагинация; одна генерация аудио дайджеста
при параллельных запросах; предупреждение о несохранённых правках.

Ограничения не скрывать: один владелец/процесс/INBOX, CDN, нет автоfallback моделей,
первый фрагмент зависит от провайдера, TTS пока готовит полный файл, есть лимиты
медиа, расписание не работает при выключенном компьютере. Удаление — перенос в
серверную корзину; просмотр/восстановление корзины через почтового провайдера.
SMTP accepted не равен доставке. Аппаратный микрофон и выбранный владельцем
получатель для реальной доставки требуют ручной проверки.

Модельные названия, цены и доступность перед публикацией проверить заново.
Реферальную ссылку https://anymodel.org/?ref=yakvenalex сохранить в README.
Демонстрации и скриншоты для статьи — только синтетические данные.
