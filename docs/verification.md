# Проверки реализации

Проверки выполнены 11 ноября 2026 года. Обычные тесты используют временную SQLite,
внедрённые fake gateways и запрет внешних соединений. Проверено на Python 3.13.

## Автоматические проверки

Команды: `uv run pytest -q`, `uv run ruff check src tests scripts migrations`,
`uv run mypy`, `uv run alembic upgrade head`, `uv run alembic check`.

**Итог: 43 теста прошли, Ruff и mypy прошли, Alembic не обнаружил расхождений.**

Покрыты авторизация (header/cookie, exp, алгоритм, audience, subject, CSRF, logout),
задачи и сроки, черновики, загрузки и защищённые media, явное подтверждение ASR,
дайджест и уникальный день, rollback, идемпотентность, восстановление прерванного
диалога, очистка только просроченных MP3, ошибки 429/503/524 и ограничение повторов,
полный цикл Agents SDK с fake model. Запуск тестов не тратит баланс и не отправляет писем.

## Ограниченные реальные smoke-проверки

`uv run python scripts/smoke.py --mail --ai --speech` — opt-in, AI и speech платные.
Части можно запускать отдельно. Вызовы AI используют только синтетический счёт
`tests/fixtures/invoice.png`; письмо не отправляется. Файлы результатов — в data/smoke,
исключены из Git. Скрипт не является тестом стабильности или сравнительным бенчмарком.

- IMAP: получена ограниченная выборка, прочитано одно письмо; FLAGS до/после одинаковы.
- TTS: настоящий MP3 (44 302 байта) получен от выбранного маршрута AnyModel.
- ASR: MP3 с синтетической командой переведён в WebM Opus, затем настоящий адаптер
  нормализовал его в OGG и получил русскую расшифровку. Команда не выполнялась.
- Vision + tools: распознаны ЖЮ-3082, 89 406,75 руб. и 19.11.2026 09:20 Europe/Moscow;
  создана одна задача в временной SQLite, финальный ответ содержит реальный ID.
- Первые vision-проверки выявили отсутствие `title` в ответах tool calls. Замена
  provider-facing аргумента на `task_title` решила воспроизводимую проблему. API/domain
  сохраняют поле `title`. Точную внутреннюю причину шлюза не утверждаем.
- Отдельный пустой ответ модели корректно признаётся ошибкой провайдера, а не успехом.

## Браузер

На настоящем приложении проверены вход, создание задачи со сроком, Swagger Authorize,
HTTP 200 для auth/me с Bearer и сброс авторизации Swagger после перезагрузки.

Дополнительные сценарии проверяются на `uv run python -m tests.e2e.demo_server`:
локальный адрес 127.0.0.1:18764, demo / demo-inbox-only. Этот стенд использует только
тестовые адаптеры, помечен в UI и предназначен для скриншотов без реальных писем.
Проверены чтение письма, создание/редактирование черновика, загрузка изображения,
создание задачи через чат, результаты tools, загрузка голоса, исправление расшифровки
и отдельная отправка, MP3-плеер (браузер декодировал файл, duration=1, readyState=4),
ручной дайджест. Демоозвучка — синтетический тон, не демонстрация качества голоса.

После итогового перезапуска проверены HTTP 200 для health, Swagger и защищённого
списка задач с токеном, HTTP 401 без авторизации. SQLite имеет режим доступа 0600.
На демостенде после перезапуска восстановились четыре сообщения и две квитанции
инструментов. Просмотр дайджеста показывает источники письма/задачи; озвучка доступна.
Аппаратная запись микрофона не подтверждена: управляемый браузер не завершил запрос
разрешения. Её следует проверить вручную; загрузка и подтверждение файла проверены.
