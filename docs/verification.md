# Проверки реализации

Проверки выполнены 11 ноября 2026 года. Обычные тесты используют временную SQLite,
внедрённые fake gateways и запрет внешних соединений. Проверено на Python 3.13.

## Автоматические проверки

Команды: `uv run pytest -q`, `uv run ruff check src tests scripts migrations`,
`uv run mypy`, `uv run alembic upgrade head`, `uv run alembic check`.

**Базовая версия: 43 теста прошли, Ruff и mypy прошли, Alembic не обнаружил расхождений.**

Покрыты авторизация (header/cookie, exp, алгоритм, audience, subject, CSRF, logout),
задачи и сроки, черновики, загрузки и защищённые media, явное подтверждение ASR,
дайджест и уникальный день, rollback, идемпотентность, восстановление прерванного
диалога, очистка только просроченных MP3, ошибки 429/503/524 и ограничение повторов,
полный цикл Agents SDK с fake model. Запуск тестов не тратит баланс и не отправляет писем.

## Ограниченные реальные smoke-проверки

`uv run python scripts/smoke.py --mail --ai --speech` — opt-in, AI и speech платные.
Части можно запускать отдельно. Вызовы AI используют только синтетический счёт
`tests/fixtures/invoice.png`; письмо не отправляется. Файлы результатов — в data/smoke,
исключены из Git. Скрипт не является тестом стабильности или сравнительным бенчмарком.

- IMAP: получена ограниченная выборка, прочитано одно письмо; FLAGS до/после одинаковы.
- TTS: настоящий MP3 (44 302 байта) получен от выбранного маршрута AnyModel.
- ASR: MP3 с синтетической командой переведён в WebM Opus, затем настоящий адаптер
  нормализовал его в OGG и получил русскую расшифровку. Команда не выполнялась.
- Vision + tools: распознаны ЖЮ-3082, 89 406,75 руб. и 19.11.2026 09:20 Europe/Moscow;
  создана одна задача в временной SQLite, финальный ответ содержит реальный ID.
- Первые vision-проверки выявили отсутствие `title` в ответах tool calls. Замена
  provider-facing аргумента на `task_title` решила воспроизводимую проблему. API/domain
  сохраняют поле `title`. Точную внутреннюю причину шлюза не утверждаем.
- Отдельный пустой ответ модели корректно признаётся ошибкой провайдера, а не успехом.

## Браузер

На настоящем приложении проверены вход, создание задачи со сроком, Swagger Authorize,
HTTP 200 для auth/me с Bearer и сброс авторизации Swagger после перезагрузки.

Дополнительные сценарии проверяются на `uv run python -m tests.e2e.demo_server`:
локальный адрес 127.0.0.1:18764, demo / demo-inbox-only. Этот стенд использует только
тестовые адаптеры, помечен в UI и предназначен для скриншотов без реальных писем.
Проверены чтение письма, создание/редактирование черновика, загрузка изображения,
создание задачи через чат, результаты tools, загрузка голоса, исправление расшифровки
и отдельная отправка, MP3-плеер (браузер декодировал файл, duration=1, readyState=4),
ручной дайджест. Демоозвучка — синтетический тон, не демонстрация качества голоса.

После итогового перезапуска проверены HTTP 200 для health, Swagger и защищённого
списка задач с токеном, HTTP 401 без авторизации. SQLite имеет режим доступа 0600.
На демостенде после перезапуска восстановились четыре сообщения и две квитанции
инструментов. Просмотр дайджеста показывает источники письма/задачи; озвучка доступна.
Аппаратная запись микрофона не подтверждена: управляемый браузер не завершил запрос
разрешения. Её следует проверить вручную; загрузка и подтверждение файла проверены.

## Тёмная тема и Markdown

После обновления UI прошли прежние 43 теста и Ruff; синтаксис обоих изменённых
JS-файлов проверен `node --check` (это проверка разработки, Node не нужен приложению).
В браузере на синтетическом стенде проверены заголовки, выделения, списки, таблица
и блок кода в сводке, диалоге и дайджесте. Проверен крестик удаления сводки и повторное
формирование; текст и плеер очищаются. Превью карточек не показывает сырой Markdown.
Тестовый текст со script/img/iframe и javascript-ссылкой не создал исполняемых
элементов, не выполнил скрипт и не сохранил опасный href. Внешняя безопасная ссылка
имеет noopener/noreferrer. Платные модели для этой UI-проверки не вызывались.

## Ручная отправка и вложения

Добавлены отдельные OutgoingEmail/DeliveryAttempt, миграция и API/UI отправки.
После расширения проходят 68 offline-тестов, включая MIME с кириллическим именем,
файлы, подтверждение, два параллельных запроса, повтор request_id, привязку к содержимому,
отказ SMTP, обрыв DATA, восстановление sending → unknown и запрет отправки агентом.
Ruff, mypy внутренних границ и синтаксические проверки JS проходят.

Реальный SMTP TLS/login/NOOP прошёл: messages_sent=0. Выбранная модель вернула тему/текст
по синтетическому наброску; полный агентный цикл сохранил один исходящий черновик
с настоящим ID во временной SQLite, без отправки. Эти результаты не проверяют доставку.

На синтетическом браузерном стенде проверены AI-заполнение, ручная правка, загрузка
двух файлов, сохранение и восстановление после перезапуска, просмотр перед отправкой,
возврат к правкам, подтверждение через fake SMTP и локальная история. После sent редактор
и повторная отправка заблокированы; консоль браузера без ошибок. Реальные письма
во время этих проверок не отправлялись. Первую реальную отправку/доставку нужно проверить
на адресе, который пользователь выберет сам.

## Прочитанность IMAP

81 offline-тест прошёл. Новые тесты проверяют GET/summary/agent/digest без изменения
флагов, read/unread и счётчики, групповой частичный результат, строгий boolean,
401/403/CSRF, UIDVALIDITY, отсутствие UID, отказ и игнорирование STORE, сохранение других
флагов, регистр \Seen, readonly-чтение и отсутствие SELECT у STATUS. Ruff и mypy прошли.

`uv run python scripts/smoke.py --mail-read-state` на настоящем ящике: одно письмо,
изменение подтверждено отдельным соединением, original_flags_restored=true,
other_flags_preserved=true. Реальные письма не отправлялись, AI не вызывался.

В браузере на синтетической почте проверено: открытие → «Прочитано», счётчик 1 → 0,
письмо исчезает из непрочитанных; обратная кнопка → счётчик 1 и возврат в список.
Оба групповых действия работают; во «Всех письмах» отображаются фактические отметки.

## Удаление диалогов

86 offline-тестов прошли; Ruff, mypy и node --check прошли. Новые интеграционные
проверки: DELETE с Bearer и cookie/CSRF, 401/403/404/409, сохранение созданной задачи
и соседнего диалога, запрет воскрешения повторным POST, удаление 501 записи каждой
зависимой таблицы, rollback и отказ во время реального конкурентного запроса к fake
ассистенту. Незавершённый persisted run блокирует удаление до recovery.

В браузере на синтетическом стенде проверены отправка сообщения, список истории
с отдельными крестиками, открытие подтверждения и отмена с сохранением истории.
Окончательная очистка проверена через API в автоматических тестах. Пользовательские
диалоги не удалялись. Платные провайдеры и реальная почта для этой функции не вызывались.
Изменений схемы БД нет; текущая миграция bdf0d9df1ef2 (head).

## Иконки панели ввода

86 offline-тестов и Ruff прошли, JS синтаксис проверен node --check. В браузере
на demo проверены загрузка PNG скрепкой и загрузка синтетического MP3 говорящим
смайлом: открылось подтверждение расшифровки, после обработки SVG микрофона
восстановлен, кнопка снова активна. Запись микрофоном в этой UI-правке не запускалась.
На рабочем сервере проверены отображение трёх SVG и доступные названия кнопок.

Фильтры задач: в браузере подтверждено восстановление двух градиентов стрелки
в computed background-image; переключение статуса/срока и возврат к исходным
значениям работают. CSS-правка не меняет прикладную логику.

Swagger API: ссылка использует target=_blank и rel=noopener noreferrer.
Браузерный клик открыл отдельную вкладку /docs, исходная вкладка осталась на задачах.
Проверка защищённых страниц прошла (1 тест).
